# Backend Setup Instructions

## Environment Variables

Before running the backend, you need to set up your `.env` file with an Alchemy API key:

1. Create a `.env` file in this directory
2. Add your Alchemy API key:
   ```
   ALCHEMY_API_KEY=your_actual_alchemy_api_key_here
   ```

You can get a free API key from https://alchemy.com/

## Running the Server

```bash
yarn start
```
